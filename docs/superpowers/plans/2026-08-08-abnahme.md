# Abnahme — Neugestaltung der Oberfläche

Was ohne Beamer prüfbar war, ist bereits abgehakt und mit einem Bildschirmfoto
belegt. Der Rest braucht den echten Optoma.

## Bedienung

- [x] Kein Kontakt zum Beamer: Klartext-Meldung ohne technischen Fehlertext
- [x] Beamer läuft: Statuszeile, Chips, Kacheln, roter Ausschalten-Balken
- [x] Bild ausgeblendet: gelber Streifen mit „Bild wieder zeigen"
- [x] Ton stumm: Chip wird hervorgehoben, Video bleibt unberührt
- [ ] Beamer aus: genau ein Knopf, sonst nichts
- [ ] Einschalten: Knopf sperrt, Aufwärmen wird angezeigt, danach erscheinen die Kacheln
- [ ] Bildquelle wechseln: Kachel wird nach Bestätigung durch den Beamer hervorgehoben
- [ ] Ausschalten: Rückfrage erscheint, Abbrechen tut nichts, Bestätigen schaltet aus
- [ ] Abkühlen: Einschalten ist gesperrt, bis der Beamer „Aus" meldet
- [ ] Fernbedienung am Beamer benutzen: die Oberfläche zieht binnen ~5 Sekunden nach
- [ ] Netzwerkkabel ziehen: nach ~20 Sekunden „Kein Kontakt zum Beamer"
- [ ] Kabel wieder einstecken: die App findet von allein zurück

## Technik-Seite

- [x] Zahnrad öffnet die Seite, „Zurück zur Bedienung" führt heraus
- [x] Vier Blöcke: Verbindung, Bildquellen, Darstellung, Protokoll
- [ ] Verbindung testen meldet Erfolg mit Gerätenamen
- [ ] Netzwerksuche zeigt Fortschritt und Treffer
- [ ] Eingänge einlesen füllt die Tabelle, vergebene Namen bleiben erhalten
- [ ] Umbenennen, Haken und Umsortieren wirken sofort auf die Bedienung
- [ ] Protokoll kopieren legt den Text in die Zwischenablage
- [ ] Einrichtung neu starten führt in den Assistenten

## Darstellung

- [x] Hell und dunkel sind vollständig durchgezeichnet
- [x] Hoher Kontrast wirkt: größere Schrift, kräftigere Ränder
- [x] Keine Farbe ist fest verdrahtet, alles läuft über die Variablen
- [ ] ◐ in der Kopfzeile schaltet um, Wahl übersteht einen Neustart
- [ ] „Wie das Betriebssystem" folgt einem Wechsel des Systemdesigns

## Einrichtung

- [x] Ohne Einstellungsdatei startet der Assistent bei Schritt 1
- [x] Das Zahnrad ist während der Einrichtung ausgeblendet
- [ ] Suche findet den Optoma, Auswahl führt zu Schritt 2
- [ ] Schritt 3 listet die echten Eingänge mit Vorschlagsnamen
- [ ] Abbruch in Schritt 3, Neustart: es geht bei Schritt 2 weiter
- [ ] Ohne gefundenen Beamer erscheint die Prüfliste, nicht eine Fehlermeldung
